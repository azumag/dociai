# 政経ニュース・ランダウン

政経ニュースコーナーのスライドと発話項目を、配信前の編集から本番中の手動再生まで管理する操作卓です。
AIペルソナや掛け合い台本の自動生成とは分離し、まず番組進行データを安定して扱うことを目的にしています。

## 起動

ブラウザ版:

```bash
python3 scripts/serve.py 8080
```

`http://localhost:8080/rundown.html` を開きます。DOCI操作卓の上部にある「政経ランダウン」からも移動できます。

Electron版:

```bash
npm run electron:start
```

DOCI操作卓の上部にある「政経ランダウン」を開きます。Electron版ではVOICEVOXへの通信を既存のMain-process IPC経由で行います。

## MVPでできること

- 番組名と放送日の編集
- スライドの追加、削除、並べ替え
- 16:9プレビューと前後移動
- タイトル、要点、出典、進行メモの編集
- スライドごとの発話項目の追加と編集
- 発話項目ごとのVOICEVOX手動再生と停止
- LocalStorageへの自動保存
- JSONのインポートとエクスポート

初期サンプルには、オープニング、中東情勢、米国と日本経済、消費税、こぼれ話、まとめの枠が入っています。ニュース本文や数値は放送前に最新情報へ差し替えてください。

## VOICEVOX

既定の接続先は `http://127.0.0.1:50021` です。VOICEVOX Engineを起動し、画面右側で話者IDと速度を設定します。

ブラウザ版はローカルのVOICEVOX Engineへ直接接続します。Electron版はRendererのCSPを緩めず、DOCI既存のVOICEVOX IPCサービスを利用します。

## 保存データ

保存データのschema versionは `1` です。スライドには以下を保持します。

- セクション
- 小見出し
- タイトルとサブタイトル
- 要点
- 出典表示
- 進行メモ
- 発話項目

このJSONを共通データとして、今後Google Slides書き出し、OBS表示同期、ニュース調査結果の取り込み、AI台本生成を追加します。
